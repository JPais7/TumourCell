# Kill criteria

## Stop

- Patient/sample mapping or treatment timing cannot be reconstructed reliably.
- No independent cohort can test the locked primary estimand.
- The purported residual program is not reproducible under reasonable QC/state definitions.
- Patient-level external effects are null or directionally inconsistent.

## Pivot

- If CNA matching is unreliable, pivot from “within-clone reprogramming” to the weaker claim “treatment-associated program redistribution.”
- If malignant programs fail but immune trajectories reproduce, pivot to a narrowly defined immune pharmacodynamic question.
- If TNBC external validation is inaccessible, evaluate ER+ FELINE as the primary context rather than silently weakening independence.

## Redesign

- If pretreatment nondetection dominates, redesign around detection limits rather than state emergence.
- If regimen heterogeneity dominates, restrict to one treatment class and abandon pan-treatment claims.
- If spatial series are not temporally matched, use spatial data only for localization, not transition constraints.

## Do not advance to virtual perturbation

- Predictive performance does not generalize.
- Candidate regulators are unstable across reasonable models.
- Perturbation predictions merely track proliferation or cytotoxicity.
- No feasible orthogonal perturbational evidence exists.
