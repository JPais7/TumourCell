# Latent-state specification

The versioned encoder is the sole new representation API. `latent_state_v1` is explicitly a prototype, not a final biological representation. It records genes, weights, gene-level scaling, normalization, transformation, reference, required/optional modalities, missingness rules, provenance, version and a SHA-256 hash. Continuous dimensions are prototype axes. P8 and State_01–04 remain candidate features. Tumour state is represented as `T[t] = p(z | tumour,t)` with mean, variance, quantiles, proportions, empirical low-density regions, entropy and optional mixture components.

Stress/cell-cycle analyses must report unadjusted, covariate-adjusted and residualized results. Unadjusted is primary; any signal removed by adjustment is reported explicitly as potentially biological rather than silently discarded. Uncertainty is decomposed into measurement uncertainty, coverage penalty, sampling uncertainty and extrapolation/missing-required-modality flags; the combined `uncertainty_score` is a heuristic, not a calibrated error bar. A score below configured cell/gene thresholds is `INSUFFICIENT`, not missing data.
