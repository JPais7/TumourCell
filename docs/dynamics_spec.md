# Dynamics specification

The initial target is `p(z[t+1] | z[t], treatment[t])`, using the interpretable `ContinuousTransition` regression API and optional categorical matrices only for explicitly discretized tests. Treatment is an explicit covariate and rows must already be patient-level; duplicate cell-level rows fail closed. Patient-specific counterfactual simulation, neural ODEs, transformers and reinforcement learning are outside the validated scope. The mechanistic representation is `z=(clone, cellular_state, environment)`; without adequate assignment quality, temporal overlap, abundance and QC, selection and plasticity are `NOT_IDENTIFIABLE`.
