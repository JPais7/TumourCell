# Phase 4.9.11 — Implementação clone–estado

GSE291678/GSE291679 foi seleccionado como candidato principal: fornece scRNA-seq e barcodes clonais ClonMapper em fases de doxorrubicina, permitindo comparar frequência clonal e estados dentro de clone. GSE326012 fornece validação mecanística independente com CloneTracer em MCF7. EGAS00001007242 é mantido como candidato de ligação genómica, mas requer acesso controlado.

Esta implementação distingue barcode de linhagem experimental de genótipo somático. Permite um teste observacional de selecção versus redistribuição de estados, sem inferir causalidade, linhagem física persistente ou benefício clínico. A Phase 5 continua bloqueada.
