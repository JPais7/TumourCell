# Validation datasets

## Locked external sets

- **Yan/ARTEMIS 2026:** test whether a Kim-derived program is detectable pretreatment and associated with residual disease; spatially locate it. Do not redefine the program here.
- **Shiao GSE246613:** test direction of treatment-associated change under a different TNBC regimen. Failure is informative and may demonstrate regimen specificity.
- **GSE205472:** test whether the signal is a generic HR+ chemotherapy/stress program rather than TNBC-specific.
- **Wu GSE176078 and Pal GSE161529:** test state recurrence and specificity only; neither validates treatment response.

Validation data cannot be used to select genes, choose signs, set thresholds, decide covariates, or pick the successful outcome.
